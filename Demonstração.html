🧪 Painel do professor — CSS original vs. minificado (clique para abrir)
ANTES — estilos.css (fácil de ler, ~250 bytes) 
.card {
	background: #1e293b;
	border-radius: 10px;
	padding: 14px;
}

.card h3 {
  font-size: 15px;
  margin-bottom: 4px;
}
DEPOIS — estilos.min.css (~130 bytes, ≈48% menor) 
.card{
	background:#1e293b;
	border-radius:10px;
	padding:14px
}

.card h3{
	font-size:15px;
	margin-bottom:4px
}

Gerado com: npx postcss estilos.css -o estilos.min.css (usando PostCSS + cssnano). O navegador entende as duas versões perfeitamente — a diferença é só o tamanho do download.
