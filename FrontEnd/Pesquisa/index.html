Pesquisa de Aprofundamento — Programação Front-End

E. E. Profª. Olympia Barth de Oliveira

Parte 1 — Pesquisa Teórica

Responda, com suas próprias palavras e pelo menos um exemplo real (trecho de código ou site) para cada item, aos quatro blocos abaixo. Extensão sugerida: entre meia página e uma página por bloco.

1. Flexbox

  • Explique a diferença entre o eixo principal e o eixo transversal no Flexbox, citando as propriedades que controlam cada um (ex.: justify-content, align-items).
  • Indique um caso de uso em que o Flexbox é a escolha mais indicada de layout.

2. CSS Grid

  • Explique a diferença entre um layout construído com Flexbox e um construído com CSS Grid, e em que tipo de estrutura (ex.: grade de cards, layout de página inteira) o Grid costuma ser mais indicado.
  • Pesquise as propriedades grid-template-columns, grid-template-rows e gap e explique o papel de cada uma.

3. Performance web

  • Explique o que é Lazy Loading, como ativá-lo em imagens (atributo loading) e em que situações ele traz mais benefício.
  • Explique o que é minificação de CSS/JavaScript e pesquise mais uma técnica de performance (ex.: compressão de imagens, cache do navegador, uso de CDN).

4. Acessibilidade

  • Explique o papel do atributo alt e pesquise pelo menos dois atributos ARIA, explicando para que servem.
  • Pesquise a ferramenta WAVE (ou outra, como o Lighthouse) e explique como ela ajuda a identificar problemas de acessibilidade em uma página.

Parte 2 — Atividade Prática

Escolha UMA das três opções abaixo:

  1. Auditoria de uma página existente — Escolha um site do seu dia a dia, rode uma análise com o WAVE (ou Lighthouse) e liste 3 problemas de acessibilidade e/ou performance encontrados, propondo a correção de cada um (ex.: adicionar alt, adicionar loading="lazy", minificar arquivos).
  2. Construção de um layout — Crie uma pequena página (HTML/CSS) usando Flexbox e CSS Grid combinados, aplicando lazy loading em pelo menos uma imagem e ao menos duas boas práticas de acessibilidade (alt descritivo, contraste adequado, navegação por teclado ou uso de ARIA).
  3. Flexbox x Grid na prática — Implemente o mesmo layout (ex.: uma galeria de cards) primeiro com Flexbox e depois com CSS Grid, e escreva uma comparação das vantagens e limitações de cada abordagem para esse caso.
