1

Flexbox

Alinhamento em uma dimensão — como no CSS Froggy

Conceitos-chave

O Flexbox (display: flex) organiza os elementos filhos de um container ao longo de um eixo — horizontal (linha) ou vertical (coluna). Cada propriedade do Flexbox controla o alinhamento em relação a um desses dois eixos:

EixoPropriedadePara que serve
Principal (main axis)justify-content Alinha os itens ao longo da direção definida por flex-direction (por padrão, horizontal).
Cruzado (cross axis)align-items Alinha os itens na direção perpendicular ao eixo principal.

Valores mais comuns de justify-content

  • flex-start — agrupa os itens no início do eixo principal.
  • center — centraliza os itens ao longo do eixo principal.
  • space-between — distribui os itens com espaço igual entre eles.
  • space-around — distribui os itens com espaço igual ao redor de cada um.
.container {
  display: flex;
  flex-direction: row;      /* eixo principal: horizontal */
  justify-content: center;  /* centraliza no eixo principal */
  align-items: center;      /* centraliza no eixo cruzado */
  flex-wrap: wrap;          /* permite quebrar linha se não couber */
}
Pegadinha comum: justify-content e align-items são fáceis de confundir. Lembre-se: justify = eixo principal; align = eixo cruzado. Se o layout é uma linha (row), justify-content mexe no eixo horizontal; se for uma coluna (column), justify-content passa a controlar o eixo vertical.
Sobre o CSS Froggy: cada fase do jogo apresenta um desafio de posicionamento que só é resolvido escolhendo a propriedade e o valor certos de Flexbox — é uma forma prática de fixar a diferença entre as propriedades de eixo principal e eixo cruzado.
2

CSS Grid

Alinhamento em duas dimensões — linhas e colunas

Conceitos-chave

Enquanto o Flexbox trabalha bem em uma dimensão por vez, o CSS Grid (display: grid) organiza os elementos em linhas e colunas ao mesmo tempo, o que o torna ideal para layouts de página inteira (cabeçalho, menu lateral, conteúdo, rodapé).

Definindo colunas com grid-template-columns

A unidade fr ("fraction") representa uma fração do espaço disponível no container. O total de frações definidas na propriedade divide o espaço proporcionalmente:

.layout {
  display: grid;
  grid-template-columns: 1fr 2fr 1fr;
  gap: 16px;
}
Como ler 1fr 2fr 1fr: são 3 colunas e 4 frações no total (1 + 2 + 1). A primeira e a terceira coluna recebem 1 fração cada (1/4 do espaço); a coluna do meio recebe 2 frações — o dobro do espaço das outras duas.

Flexbox vs. CSS Grid

FlexboxCSS Grid
DimensãoUma (linha OU coluna)Duas (linhas E colunas)
Uso típicoAlinhar itens dentro de um componente (menu, card, barra de botões) Estruturar a página inteira (grid de seções)

Lazy Loading

Carregar recursos só quando forem necessários

Conceitos-chave

Lazy Loading ("carregamento preguiçoso") é uma técnica que adia o carregamento de imagens e outros recursos até o momento em que eles estão prestes a entrar na área visível da tela do usuário (o viewport), em vez de carregar tudo de uma vez assim que a página abre.

<img src="banner.jpg" loading="lazy" alt="Banner promocional">

Por que isso importa

  • Carregamento inicial mais rápido: a página fica pronta para uso sem esperar por imagens que o usuário ainda nem viu.
  • Economia de dados: se a pessoa não rolar até o final da página, esses recursos nunca são baixados.
  • Melhora métricas de performance como o LCP (tempo até o maior elemento visível carregar).
Pegadinha comum: Lazy Loading não reduz o tamanho dos arquivos (isso é minificação/compressão) e não é sobre carregar "tudo de uma vez" — é justamente o oposto: adiar o que ainda não é visível.

Performance e minificação

Deixar a página mais leve e medir o resultado

Minificação de CSS

Minificar um arquivo CSS significa remover tudo que é desnecessário para o navegador entender o código — espaços em branco, quebras de linha, comentários — sem mudar o que ele faz. O resultado é um arquivo menor, que trafega mais rápido pela rede e reduz o tempo de carregamento da página.

Antes 
.card {
  padding: 16px;
  /* espaçamento do card */
  color: #333;
}
Minificado 
.card{padding:16px;color:#333}

Ferramentas de análise de performance

FerramentaPara que serve
Google LighthouseIntegrado ao Chrome DevTools; audita uma página e gera um relatório de performance, acessibilidade, boas práticas e SEO.
PageSpeed InsightsFerramenta do Google, baseada no mesmo motor do Lighthouse, que analisa uma URL pública e sugere melhorias de velocidade.
Pegadinha comum: nem toda ferramenta de "análise" é sobre performance. O Google Analytics mede tráfego e comportamento de usuários (não velocidade), e o W3C Validator verifica se o código HTML/CSS segue as regras da especificação (não mede tempo de carregamento).

Acessibilidade e atributos ARIA

Tornar a página utilizável por tecnologias assistivas

Conceitos-chave

ARIA (Accessible Rich Internet Applications) é um conjunto de atributos HTML que fornece informações extras para tecnologias assistivas — como leitores de tela — quando a estrutura HTML sozinha não é suficiente para descrever o que um elemento faz ou representa.

AtributoPara que serve
aria-labelDá um nome acessível a um elemento sem texto visível (ex.: um botão que só tem um ícone).
aria-hidden="true"Esconde um elemento puramente decorativo da leitura por tecnologias assistivas.
roleInforma qual é a função de um elemento (ex.: role="button" em uma <div> que se comporta como botão).
<button aria-label="Fechar janela">
  <svg aria-hidden="true">...</svg>
</button>
Por que isso importa: sem essas informações, uma pessoa que navega por leitor de tela pode não entender para que serve um botão só com ícone, ou pode ouvir a leitura de elementos puramente visuais e decorativos que não agregam nada ao conteúdo. ARIA não muda a aparência da página — é informação adicional só para tecnologia assistiva.
