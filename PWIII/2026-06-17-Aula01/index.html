Desafio — Programação Web

Listagem e Cadastro de Registros
com Banco de Dados

Vocês já sabem conectar a um banco de dados e executar comandos SQL. Agora é hora de juntar tudo isso em uma aplicação web funcional: uma tela que lista registros do banco em uma <table> e um formulário que permite cadastrar novos.

Objetivo Pré-requisitos Tema Parte 1 Parte 2 Parte 3 Passo a passo Arquivos Dicas Extras Avaliação

01Objetivo

Construir uma aplicação web com duas telas integradas:

  • Listagem: exibe todos os registros de uma tabela do banco, organizados em uma <table> HTML.
  • Cadastro: um formulário que insere novos registros diretamente no banco de dados.

✓O que vocês já sabem fazer

  • Conectar-se a um banco de dados MySQL (PDO).
  • Executar comandos SQL a partir do PHP.
  • Estrutura básica de HTML, incluindo formulários (<form>, <input>).

02Escolha do tema

Antes de programar, escolham um tema para o cadastro. A tabela do banco deve ter no mínimo 4 campos, incluindo um id como chave primária com auto incremento.

📚 Cadastro de Livros 🛒 Cadastro de Produtos 🎓 Cadastro de Alunos 🎬 Cadastro de Filmes 📇 Cadastro de Contatos

03Parte 1 — Tela de Listagem

  • Conectar ao banco de dados.
  • Executar um SELECT * na tabela escolhida.
  • Percorrer o resultado com um laço de repetição.
  • Exibir os dados em uma <table>, com <thead> mostrando o nome dos campos e uma <tr> para cada registro.
  • Se não houver registros, exibir uma mensagem como "Nenhum registro cadastrado ainda".

04Parte 2 — Formulário de Cadastro

  • Criar um formulário HTML com um <input> para cada coluna da tabela (exceto o id, que é automático).
  • O formulário deve enviar os dados pelo método POST.
  • Criar um script que receba os dados ($_POST) e execute um INSERT no banco.
  • Depois de cadastrar, redirecionar o usuário de volta para a listagem, já atualizada com o novo registro.

05Parte 3 — Integração

  • A listagem deve ter um botão ou link ("Novo Cadastro") que leva ao formulário.
  • Depois de cadastrar, o novo registro deve aparecer automaticamente na listagem, sem precisar editar nada manualmente.

→Passo a passo sugerido

  1. Planejem a tabela do banco: definam o tema e os campos (nome, tipo de dado, tamanho).
  2. Criem a tabela no banco com o comando CREATE TABLE.
  3. Reaproveitem o script de conexão (conexao.php) das aulas anteriores.
  4. Construam a listagem: SELECT + laço de repetição + table HTML.
  5. Construam o formulário em HTML puro, ainda sem lógica de banco.
  6. Construam o script de processamento: recebe o POST, faz o INSERT e redireciona.
  7. Testem o fluxo completo: cadastrem um registro e confiram se ele aparece na listagem.
  8. Capricho final: adicionem um CSS simples para deixar a tabela e o formulário apresentáveis.

06Estrutura de arquivos sugerida

</> conexao.php </> listar.php </> cadastro.php </> processar_cadastro.php
Arquivo Função
conexao.php Conexão com o banco de dados (reaproveitada das aulas anteriores)
listar.php Página principal: consulta o banco e exibe os registros em uma table
cadastro.php Exibe o formulário HTML para cadastrar um novo registro
processar_cadastro.php Recebe os dados do formulário, executa o INSERT e redireciona para listar.php

07Dicas técnicas

  • Use header("Location: listar.php"); para redirecionar depois do cadastro.
  • Validem se os campos do formulário não estão vazios antes de inserir.
  • Usem htmlspecialchars() ao exibir dados na tela, para evitar problemas com caracteres especiais.
  • Prefiram prepared statements (PDO) para inserir dados com segurança.

08Desafios extras (opcional)

  • Adicionar um botão de excluir em cada linha da tabela.
  • Exibir uma mensagem de confirmação após o cadastro ("Registro cadastrado com sucesso!").
  • Permitir ordenar a listagem por algum campo.
  • Adicionar um campo de busca/filtro na listagem.

09Critérios de avaliação

Critério O que indica um bom resultado
Conexão e consulta (SELECT) Conecta corretamente ao banco e traz todos os registros da tabela escolhida.
Exibição em table Os dados aparecem organizados em uma <table> HTML, com cabeçalho e uma linha por registro.
Formulário de cadastro Formulário funcional, com um campo para cada coluna da tabela (exceto o id).
Inserção no banco (INSERT) Ao enviar o formulário, o novo registro é realmente salvo no banco de dados.
Integração entre as telas Depois de cadastrar, o usuário retorna à listagem e vê o novo registro já aparecendo.
Organização do código Código dividido em arquivos com funções claras, indentado e de fácil leitura.
