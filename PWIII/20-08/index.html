PHP: listagem de dados e tela de cadastro

Material didático simples para explicar a lógica de uma tela de listagem e cadastro. Aqui não entra filtro, paginação, validação avançada nem camada de segurança. O objetivo é mostrar o fluxo básico e a lógica da programação.

1) Ideia geral

Em uma aplicação web com PHP, normalmente a lógica é esta:

  • Conectar ao banco de dados.
  • Executar uma consulta SQL.
  • Receber os resultados.
  • Montar a tela HTML.
  • Mostrar os dados em uma tabela.

A parte importante é entender que o PHP serve para preparar os dados e o HTML serve para apresentar esses dados em tela. O PHP não "cria a página como no Photoshop"; ele gera código HTML dinamicamente.

2) Exemplo simples de listagem

Suponha que a tabela do banco seja clientes:

CREATE TABLE clientes (
  id INT PRIMARY KEY AUTO_INCREMENT,
  nome VARCHAR(100),
  email VARCHAR(100),
  telefone VARCHAR(20)
);

Exemplo de dados:

ID Nome E-mail Telefone
1 Maria Silva maria@email.com (11) 99999-1111
2 João Souza joao@email.com (11) 98888-2222

O que a tela precisa fazer:

  • Buscar os clientes no banco.
  • Guardar em uma variável.
  • Loopar os dados.
  • Gerar cada linha da tabela.
Ver o código PHP

3) Código PHP da listagem

<?php
$host = 'localhost';
$user = 'root';
$password = '';
$dbname = 'aula_php';

$conn = new mysqli($host, $user, $password, $dbname);

if ($conn->connect_error) {
    die('Erro na conexão: ' . $conn->connect_error);
}

$sql = 'SELECT id, nome, email, telefone FROM clientes ORDER BY nome';
$result = $conn->query($sql);
?>

<table>
    <thead>
        <tr>
            <th>ID</th>
            <th>Nome</th>
            <th>E-mail</th>
            <th>Telefone</th>
        </tr>
    </thead>
    <tbody>
        <?php while ($cliente = $result->fetch_assoc()) { ?>
            <tr>
                <td><?php echo $cliente['id']; ?></td>
                <td><?php echo $cliente['nome']; ?></td>
                <td><?php echo $cliente['email']; ?></td>
                <td><?php echo $cliente['telefone']; ?></td>
            </tr>
        <?php } ?>
    </tbody>
</table>

<?php
$conn->close();
?>

Este é o padrão básico: PHP consulta e HTML exibe. O while percorre cada linha retornada pelo banco e cria uma linha na tabela.

4) Como explicar isso para alunos

A melhor forma de ensinar é mostrar a separação de responsabilidades:

  • Banco de dados: guarda os dados.
  • PHP: conversa com o banco e traz os dados.
  • HTML: estrutura a tela.
  • PHP + HTML: mistura os dados dentro da página.

Se o aluno não entender, peça que ele responda: “Qual é a etapa 1? Conectar. Etapa 2? Consultar. Etapa 3? Mostrar.” Isso ajuda a quebrar a lógica em passos simples.

5) Tela de cadastro

Agora, para cadastrar, normalmente existem duas telas (ou duas partes da mesma tela):

  1. Uma página com o formulário.
  2. Uma página que recebe os dados enviados e insere no banco.

Formulário HTML

<form action="salvar_cliente.php" method="POST">
    <label>
        Nome:
        <input type="text" name="nome" required>
    </label>

    <label>
        E-mail:
        <input type="email" name="email" required>
    </label>

    <label>
        Telefone:
        <input type="text" name="telefone">
    </label>

    <button type="submit">Salvar</button>
</form>

Arquivo salvar_cliente.php

<?php
$host = 'localhost';
$user = 'root';
$password = '';
$dbname = 'aula_php';

$conn = new mysqli($host, $user, $password, $dbname);

if ($conn->connect_error) {
    die('Erro na conexão: ' . $conn->connect_error);
}

$nome = $_POST['nome'];
$email = $_POST['email'];
$telefone = $_POST['telefone'];

$sql = "INSERT INTO clientes (nome, email, telefone) VALUES ('$nome', '$email', '$telefone')";

if ($conn->query($sql) === TRUE) {
    echo 'Cadastro realizado com sucesso!';
} else {
    echo 'Erro ao cadastrar: ' . $conn->error;
}

$conn->close();
?>

A lógica aqui é simples: o browser envia os dados do formulário para o PHP via POST. O PHP pega os valores com $_POST e grava no banco com um INSERT.

6) Qual é a lógica para seguir?

Para a maioria dos exercícios simples, siga este mapa mental:

  1. Defina a tabela e os campos que vão aparecer.
  2. Crie a página de listagem com estrutura HTML.
  3. Faça a conexão com o banco em PHP.
  4. Escreva a consulta SQL para buscar os dados.
  5. Use um loop para percorrer os registros.
  6. Imprima as linhas da tabela dentro do HTML.
  7. Crie um formulário para receber os dados.
  8. Crie outra página PHP para tratar o envio.
  9. Use INSERT para gravar os dados.
  10. Redirecione ou mostre uma mensagem de sucesso.

Em sala, esse passo a passo costuma funcionar melhor do que mostrar “um código pronto” logo de início. Primeiro o aluno precisa entender o fluxo: formulário → envio → PHP → banco → resposta.

7) Lógica de fluxo completa

Usuário abre a página de listagem
        ↓
PHP conecta no banco
        ↓
SELECT busca os dados
        ↓
PHP gera o HTML com a tabela
        ↓
Usuário clica em “Cadastrar”
        ↓
Formulário envia dados para salvar.php
        ↓
PHP recebe os dados com $_POST
        ↓
INSERT salva no banco
        ↓
Página mostra mensagem de sucesso ou volta para listagem

8) Dica importante para o professor

Se os alunos estão “colando IA” e não entendendo, o melhor é exigir que eles expliquem cada linha. Perguntas simples ajudam:

  • O que é esse SELECT?
  • Para que serve o while?
  • Quem envia os dados do formulário?
  • O que é o $_POST?
  • O que a função INSERT faz?

Quando o aluno consegue responder isso sem olhar o código, ele já entendeu o básico.
